# Telegram Bot для автопостинга

Бот для автоматической публикации постов в Telegram каналах с системой подписки.

## Функциональность

- ✅ Поддержка множества администраторов и каналов
- ✅ Различные типы контента: текст, фото, видео, документы
- ✅ Планирование публикаций по расписанию
- ✅ Система подписки с бесплатным тарифом (10 постов)
- ✅ Премиум подписка с тестовым периодом 14 дней
- ✅ Оплата через Telegram Stars
- ✅ Управление через удобное меню
